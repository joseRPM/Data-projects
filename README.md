# Data proyects
This repository contains three data projects (in Spanish, by the way). The goal was to practice data cleaning, information extraction, 
database querying, and other data-related tasks.

## Fruit and Vegetable Price Analysis
In this project, we used annual data on fruit and vegetable production from the Chilean government's database.
I performed exploratory data analysis, data cleaning, and feature engineering. We also built a small linear regression model (machine learning)
to investigate which variables had the greatest impact on price variability.
> Currently, the analysis was performed on only one product, and some useful conclusions were drawn from the results. With additional information,
> such as weather conditions or GDP during the production period, it could be possible to build a more robust model and obtain more accurate results.

## Wine Analysis
This project aimed to apply everything learned about databases. A wine dataset was used to practice SQL queries,
as well as basic database modeling. As an additional step, the query results were exported to a data visualization tool (Power BI) 
to give the results a story to tell.
